# Image Prompts: Glaux the Little Owl

Self-contained prompts for generating the seven mascot poses. Every prompt
repeats the full base description from [character-sheet.md](character-sheet.md)
so each one can be pasted on its own. Generate at 1024x1024, then trim the
padding (see the commands at the end).

Paste this first, before the seven pose prompts:

```
I am about to ask you to generate seven different poses for a book mascot.
Please use a consistent drawing style for all seven images.
```

## 1. Neutral/Default Pose

Use: general sidebars, introductions, inline use. Filename: `neutral.png`

```
Please generate a new neutral pose for Glaux the Little Owl.
A hand-drawn travel-sketchbook illustration of Glaux the Little Owl, the friendly mascot for a travel notebook about the history, culture, food and people of Turkey and Greece. Glaux is a true little owl (Athene noctua): small, round and compact, with a flat rounded head and no ear tufts, warm earth-brown plumage (#7a5a3a) covered in cream spots, bright lemon-yellow eyes under pale cream "eyebrows", a cream-white throat patch and a short pale greenish-yellow beak. Glaux wears a small Aegean-blue scarf (#1f6f8b) and a tan canvas satchel across the body with a small leather-bound travel notebook peeking out, and a sprig of three olive leaves is tucked into the satchel strap. Glaux has an alert, curious and warm expression. The character is small and compact, readable at icon size. Style: clean dark ink outlines with flat, softly shaded color fills, like an illustration in a traveler's journal; transparent background with alpha channel, suitable for embedding in a web page. No text in image.

Glaux stands upright on both feet in a relaxed, neutral pose facing the viewer directly, with a calm and friendly look. Both wings rest naturally at their sides with no specific gesture. The pose is balanced and unassuming, suitable as a general-purpose illustration.
Filename: neutral.png

Please generate a new RGBA PNG image now with a fully transparent alpha-channel background.
The background MUST be fully transparent with an alpha channel. DO NOT use a white, black or a checkered background.
```

## After Generating

Save each image in `docs/img/mascot/` with the filename above, then trim the
transparent padding so the owl fills the 90px admonition height:

```bash
for f in neutral welcome thinking tip warning encouraging celebration; do
  python "$BK_HOME/src/image-utils/trim-padding-from-image.py" "docs/img/mascot/$f.png"
done
```
