## Critical Rule

**This image must contain absolutely no text of any kind: no title, no heading,
no labels, no letters, no numbers, no digits, no arrows, no callout lines, no
scale bars, no signature and no watermark.** Sails, shields, banners, and ship
sides must show only plain colors or simple abstract patterns that are clearly
not writing: no Greek letters, no Persian or cuneiform signs. The names and
numbered markers are added later as an interactive HTML overlay, and any text
in the picture would clash with it.
