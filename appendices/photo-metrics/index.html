    How This Report Was Made¶

    This page is generated by a Python script, not written by hand. The steps are:

    1. Export the album. Google Photos no longer lets a script read a shared album directly, so the album was downloaded with Google Takeout. The export includes a small JSON file for each photo and video, holding the time it was taken and its GPS location.
    2. Read the metadata. The script reads only those JSON files. It never opens or copies the photos themselves, and the export stays on the author's computer; it is never added to the repository.
    3. Match each item to a place. Each item with a GPS location is assigned to the nearest landmark in data/chapter-places.json whose radius contains it. Landmarks are grouped into areas by city or port. Items outside every landmark count as "Elsewhere," and items with no GPS data count as "No location recorded."
    4. List the book photos. The photos chosen for the chapters come from data/photo-picks.csv. They are published with all location data removed.
    5. Write the page. The script rewrites everything above this section between two hidden markers. It also saves the same numbers as photo-metrics.json.

    The source code is scripts/google_photos_takeout.py on GitHub. It uses only the Python standard library. To regenerate this page after a new export, run:

    python3 scripts/google_photos_takeout.py data/takeout --album "Ann & Dan Eastern Mediterranean Cruise 2026"
